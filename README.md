### 🎯 Objectivo do Problema

Dado quatro gráficos de posição versus tempo (A, B, C, D), determinar e desenhar os correspondentes gráficos de velocidade versus tempo.

### 🔬 Conceitos Físicos Abordados

- **Velocidade como derivada da posição:** v = dx/dt
- **Interpretação gráfica:** A velocidade é a inclinação do gráfico posição-tempo
- **Análise de movimento uniformemente variado**
- **Descontinuidades e impulsos**

### 📊 Resumo dos Resultados

| Gráfico | Tipo de Movimento | Gráfico Velocidade-Tempo |
|---------|-------------------|--------------------------|
| **A** | Movimento rectilíneo uniforme (velocidade negativa) | Linha horizontal abaixo do eixo |
| **B** | Movimento rectilíneo uniforme (velocidade positiva) | Linha horizontal acima do eixo |
| **C** | Repouso seguido de movimento uniforme | Linha horizontal no zero + linha horizontal positiva |
| **D** | Movimento por impulsos | Impulsos verticais alternados com repouso |

### 🧮 Método de Resolução

1. **Identificar segmentos** do gráfico posição-tempo
2. **Calcular inclinações** de cada segmento
3. **Construir gráfico velocidade-tempo** usando as inclinações calculadas
4. **Interpretar fisicamente** os resultados
